# secrets

Private data repo for secret-run: **age ciphertext and value-free metadata only.**

- Format contract: FORMAT.md in secret-run (copy it here if you like; `.gitignore` already allows `/FORMAT.md`).
- Values are read with `secret run` / `secret get`; humans use `secret show` or the web UI.
- Keep this repository **private**. Everything except `store/**/*.age` and `recovery/*.age` is plaintext.
